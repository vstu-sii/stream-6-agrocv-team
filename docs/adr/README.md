| ADR | Принятое решение | Сценарии | Цена решения |
| --- | --- | --- | --- |
| [ADR-001](ADR-001-inference-boundary.md) | Браузерный клиент обращается к API; Qwen3-VL-4B выполняется внутренним серверным модулем | UC-01, UC-02 | Общие ресурсы и выпуск API/модели, ограничение независимого масштабирования |

## Продуктовая оценка

Решения сохраняют три пользовательских сценария, объяснённый отказ и различение попыток. Для каждого ADR указаны альтернативы, обоснование, цена, критерии проверки и условия пересмотра. Выбор модели описан в [порядке использования Qwen](../model-usage.md), скоуп — в [роадмапе](../roadmap.md), числовые цели — в [критериях приёмки](../acceptance.md).

## Проверка реализации

Delivery отражает браузерный клиент, API и хранилище в C4; модель — компонент внутри API. ERD сохраняет связи сессии, попытки и актуального отзыва. Контракт AI-API сохраняет состояния результата, отказа и ошибки. Quality проверяет доступ, повторы, таймауты и удаление файлов по AC.

C4, ERD, OpenAPI, compose и протокол aact команды не представлены в этом пакете. Их соответствие ADR и успешные инженерные проверки здесь не утверждаются. Статус «Принято» фиксирует проектное решение, а не завершение реализации.
