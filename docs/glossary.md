# Глоссарий v2

Предметные термины первой лабы дополнены понятиями архитектуры, AI-пайплайна и пользовательского разбора. Имена в коде — проектные обозначения сущностей, а не подтверждение реализации.

## Предметная область

| № | Термин | Определение | Имя в коде | Отличие |
| --- | --- | --- | --- | --- |
| 1 | Целевой сегмент | Начинающие дачники и владельцы участков, лично ухаживающие за яблонями ради урожая для себя и семьи | `TargetSegment` | Не коммерческие сады и не все владельцы растений |
| 2 | Культура | Вид выращиваемого растения, для которого применима модель; сейчас только яблоня | `Crop` | Не сорт яблони и не класс болезни; груша — другая культура |
| 3 | Образец | Конкретный лист конкретного растения, к которому относятся снимки и эталон | `LeafSample` | Не отдельный файл: у одного листа может быть несколько фото |
| 4 | Снимок | Одно изображение, отправленное пользователем на анализ | `LeafImage` | Не образец и не готовое заключение |
| 5 | Пригодный снимок | Изображение одного листа с различимой поверхностью и достаточным качеством для согласованного сценария | `ImageQualityCheck` | Не доказательство принадлежности к известному классу |
| 6 | Признак поражения | Видимое изменение листа, например пятно; само по себе не устанавливает причину | `VisibleSymptom` | Не подтверждённый диагноз |
| 7 | Поддерживаемый класс | Одна из четырёх категорий, между которыми различает MVP | `SupportedClass` | Не все возможные состояния растения |
| 8 | Класс без видимых признаков | Категория `healthy` в используемой разметке; в продукте означает отсутствие распознанных признаков поддерживаемых болезней | `healthy` | Не гарантия, что растение здорово |
| 9 | Парша | Предлагаемое русское имя класса `Apple___Apple_scab` для интерфейса; соответствие требует проверки специалистом | `apple_scab` | Не общее название любых пятен |
| 10 | Чёрная гниль / Black rot | Класс `Apple___Black_rot`; распознаются листовые проявления заболевания, название для интерфейса проверяет специалист | `black_rot` | Не любая плодовая гниль и не распознавание коры или яблок |
| 11 | Ржавчина типа Cedar apple rust | Конкретный тип ржавчины из класса `Apple___Cedar_apple_rust`; название для интерфейса проверяет специалист | `cedar_apple_rust` | Не все ржавчины яблони и не любая оранжевая пятнистость |
| 12 | Модель распознавания | Qwen3-VL-4B-Instruct, используемая с ограниченным промптом для определения классов листьев яблони; при необходимости дообучается на открытых данных | `DiseaseClassifier` | Готовая модель для другой задачи не обязательно распознаёт наши классы |
| 13 | Обучение | Изменение параметров модели на обучающей части данных | `TrainingRun` | Не запуск распознавания готовой моделью |
| 14 | Дообучение | Адаптация предобученных весов к классам и изображениям задачи на открытых данных | `FineTuningRun` | Выполняется при необходимости; не обучение с нуля |
| 15 | Предсказание | Результат вычисления модели для конкретного снимка | `Prediction` | Не эталон и не установленный диагноз |
| 16 | Оценка уверенности | Оценка отдельно проверенного метода принятия или отказа; числовая самооценка Qwen не считается калиброванной уверенностью | `ConfidenceScore` | Не гарантированная вероятность правильности и не обнаружение всех неизвестных случаев |
| 17 | Предварительный результат | Карточка с предполагаемым классом, ограничениями и следующим шагом | `AssessmentResult` | Не назначение лечения и не подтверждённый диагноз |
| 18 | Отказ от определения | Понятный ответ, что по этому снимку нельзя выдать поддерживаемый результат | `cannot_assess` | Не класс болезни и не вывод «здоров» |
| 19 | Неподдерживаемый случай | Чужая культура, неизвестное состояние или другой вид изображения за границами MVP | `UnsupportedCase` | Не обязательно низкая уверенность: модель может ошибаться уверенно |
| 20 | Эталонная метка | Независимо установленная и документированная категория снимка/образца | `ReferenceLabel` | Не ответ проверяемой модели |
| 21 | Golden dataset | Версионированные контрольные примеры с эталонами и происхождением для повторяемой проверки системы | `GoldenDataset` | Не учебная выборка и не случайные картинки без меток |
| 22 | Разбиение данных | Отделение train, validation и test с контролем общих листьев, растений и дублей | `DatasetSplit` | Не случайное перемешивание без проверки утечек |
| 23 | Baseline | Первое простое воспроизводимое решение, с которым сравниваются улучшения | `BaselineModel` | Не финальное качество и не обещанная точность |
| 24 | Сессия разбора | Один пользовательский эпизод с одним случаем; пересъёмки остаются внутри эпизода | `AssessmentSession` | Не каждый HTTP-запрос и не каждый повторный снимок |
| 25 | North Star | Доля успешных первичных разборов по формуле и условиям из PRD | `SuccessfulAssessmentRate` | Не accuracy, не число загрузок и не субъективная похвала интерфейсу |

## Архитектура и AI-пайплайн

| № | Термин | Определение | Имя в коде | Отличие |
| --- | --- | --- | --- | --- |
| 26 | Граница системы | То, за что отвечает приложение: ввод фото, распознавание, результат и отзыв | System boundary | Не граница всей инфраструктуры или датасета |
| 27 | Актёр | Внешняя роль с целью в продукте; здесь владелец яблони | Actor | Не внутренний модуль модели и не член команды разработки |
| 28 | Use case | Цель актёра, достигаемая за один эпизод, со сценарием и исключениями | UC-01–UC-03 | Не кнопка или отдельный HTTP-запрос |
| 29 | Контейнер C4 | Запускаемая часть системы либо хранилище данных на уровне container | C4 container | Не обязательно Docker-контейнер; модуль внутри API не отдельный контейнер |
| 30 | Компонент | Часть внутри одного контейнера с отдельной ответственностью | Component | Не обязательно самостоятельный сервис |
| 31 | API | Серверная граница между браузерным клиентом и обработкой снимка/отзыва | API | Не сама нейросеть и не интерфейс пользователя |
| 32 | AI-пайплайн | Проверка изображения, предобработка, инференс, проверка выхода и формирование состояния | Inference pipeline | Не процесс обучения модели |
| 33 | Инференс | Вычисление ответа на снимок с фиксированной версией весов | Inference | Не изменение весов и не дообучение |
| 34 | Предобработка | Подготовка изображения и текстового запроса процессором Qwen к ожидаемому входу модели | Preprocessing | Нормализация и размер должны соответствовать версии модели |
| 35 | Версия модели | Идентификация весов, процессора и конфигурации конкретного выпуска; версия промпта фиксируется отдельно | model_version | Не только имя архитектуры нейросети |
| 36 | Контракт AI-API | Форматы входа/выхода, ошибки и ограничения взаимодействия | OpenAPI | Не набор неформальных примеров запросов |
| 37 | Попытка | Один принятый снимок в сессии с собственным результатом/ошибкой | assessment_id | Другой снимок создаёт попытку; сетевой повтор того же запроса — нет |
| 38 | Идемпотентность | Повтор одного запроса не создаёт повторный эффект | Idempotency key | Не запрет пересъёмки новым снимком |
| 39 | Состояние результата | assessed, cannot_assess или error | status | Отказ и техническая ошибка не являются классами болезни |
| 40 | Метаданные разбора | Идентификаторы, состояния, версия модели, задержка и отзыв без оригинала фото | Assessment metadata | Не библиотека пользовательских изображений |
| 41 | Порог уверенности | Граница показа класса для отдельно проверенного метода оценки уверенности | Confidence threshold | Число уверенности из текста Qwen не является таким методом |
| 42 | Отрицательный пример | Вход за границами распознавания: чужая культура, кора, мусорный файл и т. п. | Negative case | Не просто фото здорового листа: healthy — известный класс |
| 43 | Macro-F1 | Среднее F1 по классам с одинаковым весом каждого | Macro-F1 | Не общая accuracy и не North Star |
| 44 | ADR | Запись решения о структуре системы с альтернативами, ценой и проверкой | ADR-001, ADR-002 | Не место для скоупа, выбора названия модели или порога метрики |
| 45 | Цена решения | Ограничения, затраты и долг, принятые вместе с архитектурным выбором | Decision cost | Не обязательно только денежная сумма |
| 46 | Проживаемость | Человек вне команды проходит UC по макету/прототипу без пояснений | Walkthrough | Самопроверка текста не заменяет внешнего участника |

| 47 | VLM | Модель, принимающая изображение и текст и генерирующая текстовый ответ; здесь Qwen3-VL-4B-Instruct | Vision-language model | Не готовый классификатор наших болезней |
| 48 | Промпт | Версионированная инструкция модели с допустимыми классами и форматом ответа | prompt_version | Не справочная карточка болезни |
| 49 | Валидация выхода | Проверка JSON, состояния и класса до показа результата | Output validation | Не доказательство правильности класса |

## Единый язык

Названия классов, состояний и целей UC одинаковы в документах, диаграмме, API и интерфейсе. `healthy` не обещает здоровье дерева. `cannot_assess` не является пятым классом. Попытка и сессия различаются, чтобы пересъёмки и сетевые повторы не искажали статистику.

При расхождении определений документы, интерфейс и контракт корректируются вместе.

## Развёртывание

| Термин | Определение |
| --- | --- |
| Веб-клиент | Страница в браузере компьютера или телефона: выбор фото, предпросмотр и карточка результата |
| Docker-образ | Версионированный пакет серверного приложения и зависимостей; не гарантия качества модели |
| Docker Compose | Описание совместного запуска приложения и необходимых хранилищ; браузер работает на устройстве владельца вне Docker |
