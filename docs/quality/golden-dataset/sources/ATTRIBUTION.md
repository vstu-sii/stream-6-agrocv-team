# Атрибуция фотографий

Фотографии: PlantVillage; Sharada P. Mohanty, David P. Hughes, Marcel Salathé. DOI: https://doi.org/10.3389/fpls.2016.01419

Источник и исходные пути каждого файла указаны в assets.jsonl. Авторская карточка: https://huggingface.co/datasets/mohanty/PlantVillage ; исходный репозиторий: https://github.com/spMohanty/PlantVillage-Dataset

В авторской карточке и README_HF.md указана лицензия CC BY-SA 3.0: https://creativecommons.org/licenses/by-sa/3.0/ . Атрибуцию и условия этой лицензии необходимо сохранять при распространении фотографий и их производных. Производные визуальные файлы этого набора распространяются на тех же условиях. Лицензия скрипта указана отдельно и не меняет условий для фото.

Оригинальные RGB-файлы переименованы без изменения пикселей. Искусственные дефекты и размерная нагрузка перечислены в transformation. Исходные названия и метки остаются у оценщика, а не передаются модели. Метки взяты из опубликованного набора; специалист команды их ещё не подтверждал.
