# Диагностика болезней листьев яблони и вишни по фото

## 1 Узкий фокус — актуальность и существующие решения

- **Проблема актуальна для выбранных культур.** Парша поражает листья и плоды яблони; пятнистость листьев вишни может вызывать преждевременное опадение. Это обосновывает работу с видимыми симптомами на листьях, но не универсальную диагностику всех заболеваний дерева. Источники: [UMN — парша яблони][apple], [UMN — пятнистость вишни][cherry].
- **Сценарий распознавания по фото уже реализован.** Plantix предлагает диагностику и рекомендации по снимку, kindwise — API оценки здоровья растений. Следовательно, ценность проекта следует искать в локальном исполнении, контролируемом наборе заболеваний и адаптации к собственным данным. Наличие аналогов подтверждает существование сценария, но не спрос именно на Desktop-версию: это остаётся гипотезой для проверки с пользователями. Источники: [Plantix][plantix], [kindwise plant.health][kindwise].
- **Главная сложность — перенос на реальные снимки.** В исследовании на PlantVillage высокая точность внутри датасета снизилась примерно до 31% на внешних изображениях. Это исторический пример с другими моделями, а не оценка Qwen; вывод для проекта — проверять качество на собственных полевых данных. Источник: [Mohanty et al., 2016][domain].

## 2 Широкий обзор — аналоги и подходы

| Аналог или подход | Что даёт | Вывод для проекта |
|---|---|---|
| [Plantix][plantix] | Готовый пользовательский сценарий «фото → диагноз → рекомендации» | Ориентир для UX; страница продукта не подтверждает возможность локальной поставки его модели |
| [kindwise plant.health][kindwise] | Готовый API анализа здоровья растений | Альтернатива собственной ML-разработке при допустимости внешнего сервиса; не соответствует выбранному локальному исполнению |
| [CNN-классификация листьев][pathology] | Распознавание по меткам целых изображений без обязательных рамок пятен | Полезный baseline для проверки, оправдана ли более тяжёлая VLM |
| [YOLO-детекция парши в саду][yolo] | Локализация поражений на сложных сценах | Решает отдельную задачу поиска; не обязательна, если лист уже выбран через SAM |
| [Qwen3-VL][qwen] | Анализ изображений и текстовый ответ в одной модели | Подходит для гипотез и описания признаков; общие визуальные бенчмарки не доказывают точность по выбранным болезням |
| [SAM 2.1][sam] | Маски объектов по точкам/рамкам, автоматическая генерация масок | Подходит для выделения листа; не определяет заболевание и не гарантирует, что любая маска является листом |

**Решение:** сохранить SAM + Qwen3-VL как проверяемую архитектуру MVP. SAM отвечает за область анализа, Qwen — за состояние листа и объяснение. Это инженерный выбор на основе возможностей компонентов, а не доказательство превосходства над классификатором. Источники: [SAM][sam], [Qwen3-VL][qwen], [пример классификации яблони][pathology].

## 3 Узкий фокус — детали выбранного решения

### Пайплайн и границы результата

1. **Ввод:** фото и указанная пользователем культура. Проверка качества снимка; при необходимости — запрос крупного плана. Проектное решение: ограничить вывод видимыми симптомами листа, поскольку заболевания затрагивают разные органы. Основание: [описание парши][apple].
2. **SAM 2.1 Tiny/Small:** маска листа по точке пользователя; автоматический отбор нескольких листьев — последующее расширение. Проектное решение: интерактивный выбор в MVP уменьшает риск принять маску фона за лист. Основание: [механизм подсказок SAM][sam].
3. **Подготовка входа:** кроп по маске с небольшим запасом из исходного фото; при необходимости общий снимок вторым изображением. Проектное решение: сначала использовать маску для кадрирования, а пользу удаления фона измерить отдельно. Основание: [поддержка нескольких изображений Qwen][qwen], [влияние условий изображения][domain].
4. **Qwen3-VL-4B-Instruct:** короткий структурированный ответ — видимые признаки, гипотеза из разрешённого списка, альтернативы. Допустимые состояния: `no_visible_symptoms`, `suspected_disease`, `other_or_unknown`, `insufficient_image`. Это проектный контракт; наличие валидного JSON не подтверждает правильность диагноза. Основание: [возможности модели][qwen], [риск переноса качества][domain].

**Ограничение:** «видимых симптомов не обнаружено» не следует превращать в подтверждение здоровья дерева. SAM выделяет объект, а диагноз остаётся отдельной задачей Qwen. В проверенных источниках нет достаточного подтверждения точности готовой Qwen3-VL именно для целевого набора болезней яблони и вишни. Основание: [SAM][sam], [технический отчёт Qwen3-VL][report], [различие поражаемых органов][apple].

### Минимальное дообучение

**Стартовый вариант:** один LoRA-адаптер для двух культур; базовая Qwen3-VL-4B заморожена, сначала обучаются адаптеры языковой части. Официальный код поддерживает LoRA, а MS-SWIFT приводит вариант с замороженными визуальным энкодером и связующим модулем. При недостатке памяти исследовать QLoRA; конкретную совместимость и расход VRAM проверить пробным запуском. Источники: [официальное обучение Qwen][training], [MS-SWIFT][swift], [PEFT — QLoRA][qlora].

**Обучающий пример:** кроп целого листа после того же SAM → культура → подтверждённая метка состояния; кроп поражения из существующей YOLO-разметки добавляется опционально. Обучение только на увеличенных пятнах не повторяет вход рабочего пайплайна. Это проектная мера против смены распределения входов; исходный формат допускает несколько изображений. Основание: [формат обучения][training], [исследование переноса][domain].

**Данные:** включить листья без видимых симптомов и похожие повреждения, а не только целевые болезни. Для яблони рассмотреть Plant Pathology: авторы описывают 3 651 полевой снимок и экспертно размеченный набор. Это источник для старта, а не замена локальному тесту; доступные классы и условия использования необходимо проверить до обучения. Для вишни потребуется отдельный набор, соответствующий выбранным заболеваниям. Основание: [Plant Pathology][pathology], [симптомы вишни][cherry].

**Критерий продолжения:** если LoRA улучшает только формат ответа, но сохраняет путаницу заболеваний, сравнить адаптацию визуальных компонентов с компактным классификатором. Не считать минимальное дообучение гарантией диагностического качества. Основание: [раздельная настройка компонентов][training], [классификатор как baseline][pathology].

### Проверка перед включением в продукт

**Проектный эксперимент:** сравнить исходную Qwen, Qwen + LoRA и компактный классификатор на одинаковых кропах SAM. Все снимки одного дерева/серии держать в одной части данных; отдельно проверить новые участки и ошибки масок. Измерять macro-F1, recall каждого заболевания, долю отказов, ошибки среди принятых ответов, задержку и VRAM. Эти метрики — предложенный протокол, а не заявленные результаты. Основание: [полевой benchmark][pathology], [domain shift][domain], [группировка листьев против утечки данных][dataset].

**Локальность и лицензии:** официальные Qwen3-VL-4B-Instruct и SAM 2 имеют Apache 2.0; локальный запуск без платного API возможен. Лицензии датасетов проверяются отдельно. Для Windows заранее проверить упаковку SAM: официальный репозиторий рекомендует WSL. Источники: [карточка Qwen][qwen], [лицензия и установка SAM][sam].

**Итоговое решение:** реализовать локальный прототип с интерактивным выбором листа, ограниченной таксономией и возможностью отказа; подключать LoRA после фиксации baseline. Приёмку определять качеством на новых полевых снимках, а не красивым объяснением модели. Основание: [SAM][sam], [поддержка дообучения][training], [ограничения переноса][domain].
